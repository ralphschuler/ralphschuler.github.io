The [project catalog](/en/projects/) on nyphon.de is now generated automatically from my public GitHub Pages projects.

After a new successful deployment, the central workflow updates the catalog and adds a concise post with the related changes. Archived repositories, forks and failed deployments are not treated as new releases.

The current state is used as the baseline, so historical project changes will not suddenly appear as new posts.
